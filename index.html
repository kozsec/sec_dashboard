CVSS Vectorの読み方
CVSS v3.1

AV（攻撃経路）： N=ネットワーク / A=隣接 / L=ローカル / P=物理

AC（攻撃の複雑さ）： L=低 / H=高

PR（必要な権限）： N=不要 / L=低 / H=高

UI（ユーザー操作）： N=不要 / P=必要

S（スコープ）： U=変更なし / C=変更あり

C（機密性）： N=影響なし / L=低 / H=高

I（完全性）： N=影響なし / L=低 / H=高

A（可用性）： N=影響なし / L=低 / H=高

CVSS v4.0

AV（攻撃経路）： N=ネットワーク / A=隣接 / L=ローカル / P=物理

AC（攻撃の複雑さ）： L=低 / H=高

AT（攻撃条件）： N=なし / P=あり

PR（必要な権限）： N=不要 / L=低 / H=高

UI（ユーザー操作）： N=不要 / P=必要

VC（機密性）： N=影響なし / L=低 / H=高

VI（完全性）： N=影響なし / L=低 / H=高

VA（可用性）： N=影響なし / L=低 / H=高

SC（変更後の機密性）： N=影響なし / L=低 / H=高

SI（変更後の完全性）： N=影響なし / L=低 / H=高

SA（変更後の可用性）： N=影響なし / L=低 / H=高
