# Purpose
Collect news on security incidents, government agency activities, and vulnerability information, and display them on a dashboard.

# Target of Monitoring
- Corporate security incidents
- Security information from ministries and government agencies
- Updates from security-related organizations
- Vulnerability information
- Other important security information

# Functions
Displays the following processing results on the dashboard:
- Automated information gathering
- Detection of updates and new information
- Vulnerability severity assessment
